# Kyustendil Screen — V4

Това е V4 на сайта, изграден по заключените решения от разговора.

## Заключен бранд
- Използва се заключеното лого от разговора: `assets/kyustendil-screen-logo.png`.
- Черно = основен текст и структура.
- Златно = вторични действия и акценти.
- Синьо = основните / важните CTA бутони.
- Светъл кремав/бял фон; няма тежки черни секции.

## Страници
- `index.html` — Начало
- `lokacii.html` — Локации
- `ceni.html` — Пакети и цени
- `kak-raboti.html` — Как работи
- `primeri.html` — Примерни реклами
- `reklamiray.html` — Пусни реклама
- `partneri.html` — За партньори
- `kontakti.html` — Контакти

Всички менюта и основни бутони водят към отделни страници, а не към секции чрез скрол.

## GitHub Pages
1. Качи всички файлове от папката в root на repository `Reklami`.
2. GitHub → Settings → Pages.
3. Deploy from a branch → `main` → `/ (root)`.
4. След публикуване направи hard refresh на телефона, ако се вижда старият CSS.

## Забележка за логото
PNG файлът е технически изрязан от заключеното лого само за премахване на излишното бяло поле и по-добро поставяне в header/footer. Самият дизайн не е променян.
