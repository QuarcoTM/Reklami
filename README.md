# Kyustendil Screen — GitHub Pages сайт

Готов статичен многостраничен сайт за пилотна рекламна мрежа в Кюстендил.

## Страници
- `index.html` — Начало
- `lokacii.html` — Локации
- `ceni.html` — Пакети и цени
- `kak-raboti.html` — Как работи
- `reklamiray.html` — Форма за рекламодатели
- `partneri.html` — Форма за партньорски локации
- `kontakti.html` — Контакти

## GitHub Pages
1. Създай repository, напр. `kyustendil-screen`.
2. Качи всички файлове в root.
3. Settings → Pages.
4. Deploy from a branch → `main` → `/ (root)`.
5. Save.
