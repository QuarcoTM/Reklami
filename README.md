# Kyustendil Screen — GitHub Pages сайт

Това е изцяло преработена версия на сайта, направена **без вградени screenshot снимки** и **без рязане от статична картинка**. Всичко е изградено наново с HTML, CSS и малко JavaScript.

## Какво има вътре
- `index.html` — начална страница
- `lokacii.html` — локации
- `ceni.html` — пакети и цени
- `kak-raboti.html` — как работи
- `reklamiray.html` — форма за рекламодатели
- `partneri.html` — форма за партньорски локации
- `kontakti.html` — контакти
- `styles.css` — всички стилове
- `script.js` — мобилно меню + форми
- `assets/logo.svg` — базово лого

## Как да го качиш в GitHub Pages
1. Създай нов repository в GitHub.
2. Качи всички файлове от тази папка в root на repository-то.
3. В GitHub отвори **Settings → Pages**.
4. Под **Build and deployment** избери **Deploy from a branch**.
5. Избери `main` и `/ (root)`.
6. Запази.
7. След 1–2 минути сайтът ще излезе на адрес от типа:
   `https://username.github.io/repository-name/`

## Какво трябва да смениш преди реален старт
- реалния телефон
- реалния email
- реалните адреси на локациите
- финалните пакети и цени
- текстовете за фирма/дейност
- формите — ако искаш реални изпращания, можеш да ги свържеш към Formspree или друг backend

## Важно
Този вариант е направен да изглежда добре и на телефон, и на десктоп. Hero секцията, телевизорът, статистиките и CTA секцията са направени директно в сайта, а не като картинка.
